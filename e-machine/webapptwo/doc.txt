05 — RESPONSIVE SYSTEM
------------------------------------------------
Mobile first.

Mobile:
- Maximum application width: 430px.
- Full-height application experience.
- 2-column product grid.
- Horizontal category navigation.
- Fixed bottom navigation.
- Large touch-friendly controls.

Tablet:
- Centered application.
- Maximum width: 430px for mobile simulation.
- Optional expanded layout.

Desktop:
- Adapt application to full-width commerce
  when desired, preserving component hierarchy.
